# Camada de Infraestrutura (`infrastructure`)

Esta pasta é responsável pelas implementações técnicas e integrações externas do sistema:

- **Provedores de IA / LLM**: Clientes para OpenAI, Anthropic, Gemini, Ollama, etc.
- **Banco de Dados & Storage**: Conexões com PostgreSQL, Redis, sistemas de arquivos.
- **Mensageria / Eventos**: Integrações com Kafka, RabbitMQ, SQS, etc.
- **Rede & APIs Externas**: Requisições HTTP, Webhooks, gRPC.
