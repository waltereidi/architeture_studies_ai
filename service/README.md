# Camada de Serviço (`service`)

Esta pasta contém a lógica de negócio e orquestração da aplicação:

- **Casos de Uso (Use Cases)**: Fluxos de execução (ex: envio e validação de prompts, auditoria, execução de agentes).
- **Serviços de Domínio**: Regras de negócio puras desacopladas de frameworks de infraestrutura.
- **Interfaces / Portas**: Definição de contratos abstratos implementados pela camada de infraestrutura.
